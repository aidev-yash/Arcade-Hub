🧠 AI INTEGRATION PROMPT (NO DEPENDENCIES)

OBJECTIVE:
Integrate AI opponents into all games using pure JavaScript logic only. The AI must run fully in-browser without any external APIs, libraries, or dependencies.

---

🚫 STRICT RULES:

* Do NOT use any external APIs (OpenAI, etc.)
* Do NOT use any libraries or frameworks
* Do NOT import any packages
* Do NOT use backend/server
* Everything must be written in plain JavaScript

---

🧠 GENERAL AI DESIGN PRINCIPLES:

* AI must simulate human-like behavior using logic and rules
* Add small delay (300–800ms) before AI moves for realism
* Avoid perfectly predictable patterns
* Use randomness where needed
* Keep code modular (separate AI functions per game)

🎮 GAME-WISE AI IMPLEMENTATION:

---

1. CUT-CROSS (TIC TAC TOE AI)

Implement 3 difficulty levels:

EASY MODE:

* AI selects a random empty cell

MEDIUM MODE:

* If AI can win → take winning move
* If player can win → block move
* Else → random move

HARD MODE:

* Implement Minimax Algorithm
* AI should never lose
* Optimize for performance (avoid unnecessary recursion)

FUNCTION STRUCTURE:

* getAvailableMoves(board)
* checkWinner(board)
* minimax(board, isMaximizing)
* getBestMove(board)

Board format:

* Array of 9 elements: ["X", "", "O", ...]
