---

TOTAL ROUNDS:

SCORING SYSTEM:

Each round:

* Raja → +1000 points
* Mantri → +500 points (if correct guess)
* Sipai → +100 points
* Chor → +0 points

  → Chor gets +500 points

* If Mantri gives wrong/disrespectful reply:
  → Raja gets angry
  → Mantri gets 0
  → Chor gets +500

* If Sipai helps correctly:
  → Sipai gets +100 bonus

POINT STORAGE (VERY IMPORTANT):
